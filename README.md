# Look of the map

Focus on fidelity of the pod, the map can be simple low poly terrain with caves, canyons, jumps and big height differencess occasionally. Do a single map for now, but we will add more of them later. Do a slight inspiraction from TrackMania nations forever regarding map look, but the race should be always on dirt with no roads, but rather the terrain guiding where to ride.

# Physics

The most important part of the game, the one from which most of the fun will be derived is physics of riding the pod (futuristic racig machine). Each pod has 2 engines, left and right. The steering should not come from using arrows on the keyboard, but from applying given power to each engine separatelly. My ideais that power in left engine is controlled with keys A, S, D, F corresponding to reverse (-30%), 30%, 70% and 100% of the power, and for right engine ', ;, L, K corresponding again to reverse (-30%), 30%, 70% and 100% of the power. The difference in engine power should result in turning. When turning the pod should realisticly lean, like a motorcycle. The pods don't touch the ground, they hover slightly above it.
Additionally, when doing a jump and landing from it, the player should time the dumping truster to not damage the pod. The dumping truster is activated when pressing and holding space.

# Gameplay

The race should be a timed run with no opponents on the map. The better the time, the higher the score. There should be medals for beating certain times (bronze, silver, gold). Plain and simple. After beating at least a silver, next map will be available. Next map will be added later, after first one is polished.

# Where should it run

The game should run in the browser. I should be grafically simple, but beautiful. This can be accomplished, as the only moving thing is the pod we are steering and the maps are linear and relativelly small.
